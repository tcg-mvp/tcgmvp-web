# Phase 4 - Marketplace Intelligence

## Goal

Build a provider-independent marketplace intelligence engine capable of ingesting, validating, normalizing, storing, and analyzing active marketplace data.

Sold transaction providers will be added separately once a dependable source has been validated.

---

## Sprint 4.1

- Audit marketplace tables
- Define provider interfaces
- Define product matching rules
- Build active listing importer
- Store raw observations
- Normalize listings
- Filter incorrect listings
- Validate listing quality
- Generate market summaries
- Display active marketplace intelligence
